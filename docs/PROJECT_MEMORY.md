# ЦВЗ — память проекта (источник правды по договорённостям)

Обновлять при каждом важном решении в чате. Всё из чата либо сделано, либо явно отложено здесь.

## Публичное правило
- Не светить: заказчик, адрес проживания, адрес объекта.

## Роли
1. Админ ЦВЗ — ссылки, статистика, Sheet, галочка фрилансера, Bitrix
2. Фрилансер — ЛК, оплата по ID не на витрине, MAX
3. Соискатель — поиск, отклик, подписки, табель, рефералка, опросы
- Соискатель может стать фрилансером (апрув в админке)

## Данные / хостинг
- Вакансии: Google Sheet
- ЛК: Bitrix или РФ-хостинг (МИР). Visa/MC нет → Firebase/Supabase на платном этапе сомнительны
- MAX пока основной чат

## Юридика
- ПДн, политика, оферта фрилансерам, договор услуг/ГПХ-шаблон для самозанятых + чек НПД → info.html
