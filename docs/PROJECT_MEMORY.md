# ЦВЗ — память проекта (источник правды по договорённостям)

Обновлять при каждом важном решении в чате. Всё из чата либо сделано, либо явно отложено здесь.

## Публичное правило
- Не светить: заказчик, адрес проживания, адрес объекта.

## Роли
1. Админ ЦВЗ — ссылки, статистика, Sheet, галочка фрилансера, Bitrix
2. Фрилансер — ЛК, оплата по ID не на витрине, MAX
3. Соискатель — поиск, отклик, подписки, табель, рефералка, опросы
- Соискатель может стать фрилансером (апрув в админке)

## Данные / хостинг
- Вакансии: Google Sheet (чтение+запись через service account; для записи нужен доступ **Редактор**)
- Люди/ЛК: **Bitrix24** как хранилище контактов/сделок (ID фрилансера = ID контакта Bitrix)
- Ссылка партнёра: `?p=...` + в ссылке/поле сделки ID контакта; маппинг в Bitrix (UF + робот/БП)
- MAX пока основной чат

## Юридика
- ПДн, политика, оферта фрилансерам, договор услуг/ГПХ-шаблон для самозанятых + чек НПД → info.html

## Витрина статус
- [x] поиск ID/слов, info, account каркас, мультикопирование
- [x] группы должностей + поиск, поиск региона
- [x] местная/вахта + фикс/сделка в «Кто едет»
- [x] «Короткая вахта» без (15/21)
- [x] столбцы **МП** и **фикс/сделка** есть в Sheet → экспорт читает МП
- [ ] запись в Sheet (нужен **Редактор** для SA `cvz2026@cvz2026.iam.gserviceaccount.com`) — сами выдали Читатель при подключении; никто «не сломал»
- Аудит должностей: **все строки с заполненным МАКС** (не только с потребностью)
